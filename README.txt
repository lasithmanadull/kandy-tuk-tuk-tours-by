# Kandy Tuk Tuk Tours by Munasingha

## Files
- `index.html` — website content
- `style.css` — responsive design
- `script.js` — mobile menu, gallery lightbox, reveal animations and WhatsApp booking form

## Before publishing
1. Replace every occurrence of `94771234567` with your own WhatsApp number, including country code and without the `+`.
2. Replace `hello@kandytuktuktours.com` with your real email address.
3. Replace the sample customer reviews with genuine reviews, or remove that section until you have them.
4. Update the social media links in the footer.
5. The photos currently load from Unsplash. Replace them with your own tour photos when available.

## Preview
Open `index.html` in a web browser. Internet access is needed for the Google Fonts, map and remote photos.
